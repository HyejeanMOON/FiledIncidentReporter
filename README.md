# Field Incident Reporter Admin

基于 Next.js App Router、TypeScript 和 Tailwind CSS 的管理端项目。

## 本地开发

需要 Node.js 20.9.0 或更新版本。

```bash
npm ci
npm run dev
```

打开 http://localhost:3000 。首页源码位于 `src/app/page.tsx`。

## 检查与构建

```bash
npm run lint
npm run build
npm run start
```

`npm run start` 用于启动已经构建的生产版本。
